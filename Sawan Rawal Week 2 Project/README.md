# E-Governance Digital Service — Week 2

## Responsive Web Prototype for Digital Services

This repository contains the Week 2 design deliverables for the E-Governance Digital Service project.

### Contents

- `documentation/` — complete Week 2 design report (DOCX)
- `wireframes/` — desktop, application-form and mobile mockups
- `prototype/` — responsive HTML/CSS/JavaScript prototype

### Design focus

The prototype is designed around:
- Simple service discovery
- Clear government-service navigation
- Step-by-step application flow
- Application status tracking
- Responsive desktop, tablet and mobile layouts
- Accessibility and usability considerations

### User flow

Home → Search/Select Service → Login/Register → Applicant Details → Documents → Review → Submit → Application ID → Track Status

### How to run

Open `prototype/index.html` in a web browser.

## Week 2 Deliverable

The DOCX report documents the conceptualization, UI components, user flow, wireframes/mockups, responsive strategy, accessibility decisions, design rationale and evaluation checklist.
